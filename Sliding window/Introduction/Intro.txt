Sliding Window

Sliding Window is primarily used for:

Contiguous subarray / substring problems

Examples:

Longest substring without repeating characters
Minimum size subarray sum
Maximum sum subarray of size K
Longest subarray with at most K distinct elements
Minimum window substring

The fundamental idea:

Expand → Check → Shrink → Update answer





The two fundamental Sliding Window types

There are mainly two major types you need to master.

Type 1 — Fixed Size Window

The window size is already given.

For example:

Find the maximum sum of any subarray of size K.

Suppose:

nums = [2, 1, 5, 1, 3, 2]
K = 3

Windows:

[2, 1, 5]
   [1, 5, 1]
      [5, 1, 3]
         [1, 3, 2]

The window is ALWAYS size 3.

Template
int left = 0;
long long sum = 0;

for (int right = 0; right < n; right++) {

    sum += nums[right];

    if (right - left + 1 == k) {

        // process window

        sum -= nums[left];
        left++;
    }
}

The important formula:

window size = right - left + 1

5. Variable Size Sliding Window

This is much more important for interviews.

Here the window size is not fixed.

Example:

Find the minimum length subarray whose sum is at least target.

target = 7

nums = [2,3,1,2,4,3]

We expand:

[2]
[2,3]
[2,3,1]
[2,3,1,2]

Once:

sum >= target

we start shrinking.

[2,3,1,2] = 8

Remove 2:

[3,1,2] = 6

Now condition fails.

So:

Expand → condition satisfied → shrink


CODE TEMPLATE:

int left = 0;
long long sum = 0;
int ans = INT_MAX;

for (int right = 0; right < n; right++) {

    sum += nums[right];

    while (sum >= target) {

        ans = min(ans, right - left + 1);

        sum -= nums[left];
        left++;
    }
}
