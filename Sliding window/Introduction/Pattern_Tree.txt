        |
        ├── Count subarrays with property

        └── Count using "right - left + 1"




PATTERN FOR LONGEST AND SHORTEST:

LONGEST + condition
        ↓
Expand → If invalid, shrink → Take maximum


SHORTEST + condition
        ↓
Expand → If valid, shrink → Take minimum


lONGEST CODE:
for (right...) {

    add nums[right];

    while (sum > K) {
        remove nums[left];
        left++;
    }

    // VALID WINDOW
    ans = max(ans, window_length);
}


SHORTEST CODE:
for (right...) {

    sum += nums[right];

    while (sum >= target) {

        // CURRENT WINDOW IS VALID
        ans = min(ans, right - left + 1);

        sum -= nums[left];
        left++;
    }
}
