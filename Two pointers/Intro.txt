Two Pointers means:

Maintain two indices/pointers and move them according to some logic.

Example:

1  2  3  4  5  6
↑              ↑
L              R

You have:

int left = 0;
int right = n - 1;

Then:

while (left < right) {

    if (...) {
        left++;
    }
    else {
        right--;
    }
}
 Two Pointers has several important forms

Don't think Two Pointers is only:

left = 0
right = n-1

There are multiple patterns.
